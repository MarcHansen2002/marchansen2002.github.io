About

I've been gaming and interested in games for as long as I can remember. Throughout primary and secondary school I knew I wanted to do something with computers. When I found out that I could make my own games using programmes like scratch I knew that I wanted to do something like that and decided to go down the path of learning more advanced things going to construct and then unreal in college, later making my own engines in University.

My interests include gaming, programming and making the fundamental systems that make up a game.
